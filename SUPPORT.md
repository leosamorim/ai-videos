# Suporte

Comece por [instalação e uso](docs/GETTING_STARTED.md), [contratos do pipeline](docs/PIPELINE.md) e `npm run doctor`.

Para bugs, use o formulário de issue e informe versões, comando, mensagem de erro resumida e um caso sintético mínimo. Para dúvidas de direção editorial, descreva objetivo, público e função do efeito; teste técnico não determina qualidade artística.

Este é um projeto comunitário, sem serviço de edição, hospedagem, SLA ou suporte comercial incluído. Não é necessário compartilhar materiais privados para relatar um defeito do mecanismo.
