# Referências lembradas

Registros pessoais JSON nesta pasta são locais e pesquisados por `vid discover`.
Crie-os com `vid remember ARQUIVO.json` depois da inspeção, distinguindo avaliação
do agente de feedback humano. O formato e o fluxo estão em [SOURCES.md](../SOURCES.md).

Um render finalizado não entra automaticamente como estilo aprovado. Os projetos
existentes já são encontrados pela busca e podem ser avaliados quando relevantes.
Arquivos de terceiros não devem ser redistribuídos como se fossem assets do repo.
